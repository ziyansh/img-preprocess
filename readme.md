# 批量文件处理工具

一个基于 Python 的批量文件处理工具，提供批量重命名和批量图片缩放两大功能，支持多线程/多进程并行处理。

## 功能特性

- **批量重命名**：将文件夹内所有文件按数字序号统一重命名（如 `001.png`、`002.jpg`），支持自定义起始编号
- **批量图片缩放**：将文件夹内所有图片等比例缩放至目标宽高范围内，不拉伸变形，自动创建输出子目录

## 环境要求

- Python 3.8+
- 依赖库：
  - Pillow（图片处理）


# 安装依赖
pip install Pillow
```

## 使用方法

### 主程序入口

运行 `main.py` 进入交互式菜单：

```bash
python main.py
```
