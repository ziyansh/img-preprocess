# 批量文件处理工具

一个基于 Python 的批量文件处理工具，提供批量重命名、批量图片缩放、批量缩放补边和提取 SD 图片生成参数四大功能，支持多线程/多进程并行处理。

## 功能特性

- **批量重命名**：将文件夹内所有文件按数字序号统一重命名（如 `001.png`、`002.jpg`），支持自定义起始编号和多线程并行
- **批量图片缩放**：将文件夹内所有图片等比例缩放至目标宽高范围内（支持放大和缩小），不拉伸变形，自动创建输出子目录
- **批量缩放+补边**：先将图片等比例放大撑满目标尺寸，再用白色或透明背景居中补足到指定分辨率，适合 AI 训练数据预处理
- **提取 SD 生成参数**：读取 Stable Diffusion 生成的图片中的生成参数（PNG 从 tEXt 块的 `parameters` 键读取，JPEG 从 EXIF UserComment 字段读取），支持命令行直接传入路径、菜单选择、或主菜单粘贴路径三种使用方式

## 环境要求

- Python 3.8+
- 依赖库：

## 使用方法

### 主程序入口

运行 `main.py` 进入交互式菜单：

```bash
python main.py
```

```
========================================
         批量文件处理工具主程序
========================================
【1】批量重命名文件（数字序号）
【2】批量缩放图片（等比例）
【3】批量缩放+补边（等比例放大 + 白边/透明背景填充）
【4】提取图片生成参数（SD 参数）
【0】退出程序
========================================
请选择功能（输入数字0-4）：
```

也可直接拖拽/粘贴图片路径到菜单中，程序会自动识别并提取该图片的 SD 生成参数，并在输出后提供子菜单操作：

```
【1】返回主菜单
【2】复制到剪贴板
【3】保存为同名的 .txt 文件
```

### 命令行快速提取

直接传入图片路径即可一键提取，无需进入菜单：

```bash
python main.py "C:\path\to\image.png"
```

#### 功能 1：批量重命名

1. 选择功能 `1`
2. 输入目标文件夹路径
3. 输入起始编号（直接回车默认为 1）
4. 输入并行线程数（直接回车默认为 8）

文件将按 `001.ext`、`002.ext`、`003.ext` 的格式重命名。如果目标文件名已存在则自动跳过。

#### 功能 2：批量缩放图片

1. 选择功能 `2`
2. 输入图片文件夹路径
3. 输入目标宽度（如 `1024`）
4. 输入目标高度（如 `1536`）
5. 输入并行进程数（直接回车默认为 8）

缩放后的图片会保存在输入目录下的 `resized_{宽}x{高}` 子文件夹中（如 `resized_1024x1536`），原图不会被修改。图片按等比例缩放，确保不超出目标尺寸且不变形。

#### 功能 3：批量缩放+补边

1. 选择功能 `3`
2. 输入图片文件夹路径
3. 输入目标宽度（如 `1024`）
4. 输入目标高度（如 `1536`）
5. 选择背景颜色（直接回车=白色，输入 `t`=透明）
6. 输入并行进程数（直接回车默认为 8）

先等比例放大图片尽量撑满目标尺寸，再居中粘贴到指定背景的画布上补足到精确分辨率。

- 白色背景：输出 RGB 格式，保留原图透明度合成效果
- 透明背景：输出 RGBA 的 PNG 格式，保留透明通道

输出目录为 `padded_{宽}x{高}_白底` 或 `padded_{宽}x{高}_透明底`。

#### 功能 4：提取图片生成参数（SD 参数）

1. 选择功能 `4`
2. 输入/粘贴图片文件路径
3. 程序自动提取并显示 Stable Diffusion 生成参数

**支持的图片格式：**
- **PNG** — 从 PNG `tEXt` 文本块中读取键名为 `parameters` 的生成参数
- **JPEG** — 从 EXIF `UserComment` 字段（tag 0x9286）中读取

**三种使用方式：**

| 方式 | 示例 |
|------|------|
| 命令行传参 | `python main.py "image.png"` |
| 菜单选项 4 | 选择 `4` → 输入路径 |
| 菜单直接粘贴 | 在菜单提示下直接粘贴/拖拽图片路径即可自动识别 |

提取参数后支持子菜单操作：
- `1` 返回菜单
- `2` 复制到剪贴板
- `3` 保存为同目录下的 `.txt` 文件
- `4` 复制文件并清除 EXIF — 生成 `_EXIFclr` 后缀的新文件，已剥离所有元数据

在子菜单中继续粘贴另一张图片路径，可连续提取多张图片的 SD 参数。

### 模块独立运行

各模块也可单独运行：

```bash
# 单独运行重命名模块
python rename.py

# 单独运行缩放模块
python resize.py

# 命令行传参运行缩放模块
python resize.py /path/to/images 1024 1536
```

## 模块说明

| 模块 | 并行方式 | 说明 |
|------|---------|------|
| `rename.py` | `ThreadPoolExecutor`（多线程） | 重命名是 I/O 密集型操作，适合多线程 |
| `resize.py` | `multiprocessing.Pool`（多进程） | 图片处理是 CPU 密集型操作，适合多进程 |
| `exif_extract.py` | 无（单文件操作） | 提取 SD 图片生成参数，支持 PNG tEXt 和 JPEG UserComment |

### v1.2.0

- **新增功能 4：提取 SD 生成参数** — 读取 Stable Diffusion 图片中的生成参数，支持 PNG（tEXt 块的 `parameters` 键）和 JPEG（EXIF UserComment 字段）
- **菜单快捷路径识别** — 在主菜单直接粘贴/拖拽图片路径，自动提取 SD 参数
- **命令行直接提取** — `python main.py <图片路径>` 无需进入菜单即可提取
- **子菜单操作** — 提取参数后支持返回菜单、复制到剪贴板、保存为 `.txt` 文件
- **新增模块** `exif_extract.py` — SD 参数提取独立模块，也可单独运行

### v1.1.0

- **新增功能 3：批量缩放+补边** — 先等比例放大图片撑满目标尺寸，再用白色或透明背景居中补足，输出目录自动区分 `白底/透明底`
- **功能 2 支持放大** — 移除缩放倍率 `1.0` 的上限限制，小图也能等比放大到目标尺寸
- **日志增强** — 缩放补边功能的日志改为三段式显示：`原图 -> 缩放后 -> 补边后`，处理流程更透明
- **透明背景自动转 PNG** — 选择透明背景时自动将输出格式改为 PNG，保留 Alpha 通道

### v1.0.0

- 交互式菜单界面，支持并行处理
